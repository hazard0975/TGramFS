## Пошаговый план комплексного тестирования мульти-канального хранилища

Отмечай проверенные пункты плюсиком `[+]` или `[x]`.

### 1. Создание и первичная привязка папки к отдельному каналу Telegram
- [+] **1.1.** Создать новую пустую папку в корне виртуального диска (например, `Z:\Музыка`).
- [+] **1.2.** Нажать правой кнопкой мыши по папке `Музыка` ➔ выбрать пункт «Привязать папку к отдельному каналу Telegram».
- [+] **1.3.** Проверить появление всплывающего системного уведомления Windows в трее об успешном создании и привязке канала.
- [+] **1.4.** Открыть официальный клиент Telegram: убедиться, что появился новый приватный канал с названием «Музыка».
- [+] **1.5.** Повторно нажать ПКМ ➔ «Привязать папку к отдельному каналу Telegram» на этой же папке: убедиться, что повторный канал не создается и отображается уведомление о том, что папка уже привязана к каналу.

### 2. Прямая загрузка новых файлов и подпапок в привязанную папку (наследование канала)
- [+] **2.1.** Скопировать с ПК любой аудиофайл (например, `track1.mp3`) в папку `Z:\Музыка`.
- [+] **2.2.** Открыть Telegram и проверить: файл загрузился напрямую в канал «Музыка» (в основном общем канале этого файла быть не должно).
- [+] **2.3.** Внутри `Z:\Музыка` создать подпапку (например, `Z:\Музыка\Рок`) и скопировать туда `track2.mp3`.
- [+] **2.4.** Проверить в Telegram: `track2.mp3` также загрузился в канал «Музыка» (подпапка корректно унаследовала канал родителя).
- [+] **2.5.** Проверить подпись сообщения в Telegram (caption): путь отображается правильно (`Музыка/Рок/track2.mp3`).
- [+] **2.6.** Воспроизвести/открыть файлы с диска `Z:\` в плеере: чтение происходит на полной скорости.

### 3. Ретроспективная привязка существующей папки с файлами (миграция поддерева)
- [+] **3.1.** Создать на диске обычную папку (например, `Z:\Фото`) без предварительной привязки.
- [+] **3.2.** Скопировать туда несколько изображений (JPG/PNG) и любой документ.
- [+] **3.3.** Убедиться, что файлы изначально загрузились в **основной** канал (с генерацией фото-превью в ленте для картинок).
- [+] **3.4.** Нажать ПКМ по папке `Z:\Фото` ➔ «Привязать папку к отдельному каналу Telegram». 
- [ ] **3.5.** Проверить выполнение фоновой миграции:
  - Создается канал «Фото».
  - Сообщения пересылаются в канал «Фото» без плашки автора («Переслано от...»).
  - Для картинок превью-сообщение (`tg_preview_message_id`) пересылается **строго перед** файлом документа (в ленте превью стоит первым).
  - Файлы мигрируют в хронологическом порядке их изначальной загрузки (`tg_message_id ASC`).
  - Старые сообщения в основном канале автоматически удаляются.
  - Подписи файлов в новом канале обновляются.
- [+] **3.6.** Открыть перенесенные фото с диска `Z:\Фото`: убедиться, что они открываются без повреждений.

### 4. Автоматическое переименование канала при переименовании папки
- [+] **4.1.** В Проводнике Windows переименовать папку `Z:\Музыка` в `Z:\Моя Музыка`.
- [+] **4.2.** Зайти в официальный клиент Telegram: проверить, что название канала мгновенно сменилось на «Моя Музыка».
- [+] **4.3.** Проверить подписи у файлов внутри папки: префиксы путей обновлены с учетом нового названия папки.

### 5. Перемещение файлов внутри ОДНОГО канала (без лишнего сетевого трафика)
- [+] **5.1.** Переместить файл `Z:\Моя Музыка\Рок\track2.mp3` в корень папки `Z:\Моя Музыка\`.
- [+] **5.2.** Убедиться, что перемещение произошло моментально: в базе обновился только путь, никаких сетевых пересылок сообщений в Telegram не происходило.
- [+] **5.3.** Проверить, что подпись сообщения в Telegram обновилась на `Моя Музыка/track2.mp3`.

### 6. Перемещение отдельных файлов и папок МЕЖДУ РАЗНЫМИ каналами (`MOVE`)
- [ ] **6.1.** Перетащить файл `track2.mp3` из папки `Z:\Моя Музыка\` в корень диска `Z:\` (из персонального канала в основной канал).
- [ ] **6.2.** Проверить работу фонового воркера миграции:
  - Файл удаляется из канала «Моя Музыка».
  - Файл появляется в основном канале Telegram без плашки автора.
  - Файл на диске `Z:\track2.mp3` успешно открывается и читается.
- [ ] **6.3.** Перетащить фото из корня `Z:\` в `Z:\Фото`:
  - В целевом канале «Фото» появляются оба сообщения: превью и оригинал (превью идет первым).
  - Из основного канала старые сообщения удаляются.
- [ ] **6.4.** Переместить целую подпапку с файлами из папки одного канала в папку другого канала:
  - Все вложенные файлы пакетом переносятся в целевой канал с сохранением структуры.

### 7. Удаление в Корзину и Garbage Collection (авто-удаление канала)
- [ ] **7.1.** Удалить папку `Z:\Фото` в Корзину Проводника клавишей `Delete` (soft-delete в `$RECYCLE.BIN`).
- [ ] **7.2.** Проверить клиент Telegram: канал «Фото» **НЕ удалился**, так как файлы временно находятся в корзине.
- [ ] **7.3.** Восстановить папку из Корзины Windows: проверить, что файлы доступны и привязка к каналу сохранена.
- [ ] **7.4.** Снова удалить папку `Z:\Фото` и нажать «Очистить корзину» (перманентное удаление).
- [ ] **7.5.** Проверить в Telegram: канал «Фото» автоматически удален (так как на диске и в базе больше нет ни одного файла или папки, привязанной к этому каналу).
- [ ] **7.6.** Проверить сценарий с оставшимися файлами: если в канале оставался хотя бы один другой файл/папка, канал не должен удаляться.

### 8. Перезапуск приложения во время фоновой миграции (персистентность очереди)
- [ ] **8.1.** Запустить перемещение пачки файлов между каналами (или привязку папки с десятком файлов).
- [ ] **8.2.** Во время процесса миграции принудительно закрыть программу `TelegramWebDAV` (через трей или Диспетчер задач).
- [ ] **8.3.** Запустить `TelegramWebDAV` снова.
- [ ] **8.4.** Проверить по логам (`TelegramWebDAV.log`): воркер `ProcessChannelMigrationsAsync` при старте обнаружил незавершенные задачи в таблице `pending_channel_migrations` и без сбоев завершил перенос оставшихся файлов.

### 9. Проверка поведения при лимитах Telegram (FloodWait)
- [ ] **9.1.** При массовом переносе файлов убедиться по логам, что при возникновении `FLOOD_WAIT` приложение не зависает и не выбрасывает ошибку в UI, а корректно выдерживает паузу и возобновляет миграцию.
